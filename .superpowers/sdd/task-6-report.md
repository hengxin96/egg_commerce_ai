## Delivered Behavior

- Validates the logged-in user, ownership and `draft_uploaded` state of the asset, and the presence of a source image before creating a task.
- Moves the asset to `processing` and invisible, creates a `processing` task at `输入`, and submits asynchronous execution.
- Runs `分析中 -> 确认规划 -> 生成中 -> 完成`; planning remains a display-only node.
- Uses the exact `AI生图` template category and `主图系统提示词` or `详情图系统提示词` template name based on asset type.
- Parses and persists JSON analysis and planning output, failing the current node with `商品图规划输出不是合法JSON` for invalid JSON.
- Generates from persisted positive and negative prompts, downloads the returned temporary URL through a protected seam, stores the generated bytes, inserts the generated image record, and persists generation output.
- Completes the task by publishing the asset; failures preserve prior node outputs and leave the asset failed and invisible.
- Retries only failed tasks from their failed node, reusing analysis/planning for generation retries without invoking the text model.
- Cancels only processing tasks, makes task and asset invisible/cancelled, blocks retry, and does not delete OSS objects.
